Yang ditanya saat demo & batas ruang lingkup

OTP tidak sampai ke inbox

Konfigurasi bawaan mengirim email ke berkas log. Fungsinya jalan, tapi saat demo kode verifikasi harus dibaca dari storage/logs atau SMTP diisi dulu.

Mock sudah tidak default aktif

Sejak 9d23460 (konfigurasi produksi), AppConfig.useMock bernilai false secara bawaan dan API_BASE_URL mengarah ke tunnel Ngrok. Untuk demo cukup jalankan flutter build apk --release; flag --dart-define=USE_MOCK=false --dart-define=API_BASE_URL=<tunnel>/api tetap bisa dipakai untuk menimpanya. Mode mock masih tersedia untuk widget test.

FCM adalah modul paling berisiko

FCM masuk daftar 3 API wajib dan dosen biasanya meminta melihatnya. Sisi HP sudah lengkap (firebase_messaging aktif, token dikirim ke server lewat PATCH /api/fcm-token), dan pengirimnya sudah nyata — app/Services/FcmService.php + FcmFake masuk develop lewat merge d85aae8, satu titik panggil per transisi di ServiceStatusLogObserver. Pusat notifikasi admin juga sudah dibuat, jadi admin bisa melihat kiriman sampai ke mitra. Yang belum ada: FCM_CREDENTIALS di server. Saat demo, sampaikan bedanya — kode dan testnya selesai, kredensialnya belum dipasang.

Belum ada pembayaran asli

Tidak ada gateway QRIS maupun webhook. Pembayaran hanya mencatat status di database. Sampaikan sebagai batas ruang lingkup, bukan fitur yang gagal.
