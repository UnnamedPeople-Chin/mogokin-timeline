Aturan git yang berlaku untuk semua orang:

  • main = versi stabil/demo, jangan commit langsung. develop = integrasi backend. feature/... = kerja masing-masing.
  • Backend: cabang dari develop (kini bfc7612). Mobile: cabang dari main (0aa23c5).
  • Format commit: feat: / fix: / test: / refactor:. Tanpa trailer tambahan apa pun.
  • Push branch fitur ke remote kai. Jangan pernah --force, jangan merge sendiri ke main.
  • Deskripsi PR wajib menyebut daftar berkas yang disentuh, supaya tidak tabrakan dengan tim lain.
